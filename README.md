# Enterprise DLP Platform

## Overview

This project is a full-stack Data Loss Prevention (DLP) platform that scans PostgreSQL and MongoDB databases to identify sensitive Personally Identifiable Information (PII).

The system provides:
- Sensitive data discovery
- Realtime scan progress
- Findings management
- Dashboard analytics
- Review workflow
- Export reports

---

# Features

## Backend
- Node.js + Express.js
- MongoDB
- PostgreSQL scanning
- JWT Authentication
- Socket.IO realtime updates
- MVC architecture
- Encrypted datasource credentials

## Frontend
- React.js
- Redux Toolkit
- Tailwind CSS
- Recharts analytics
- Pagination
- Export CSV/PDF
- Responsive dashboard
